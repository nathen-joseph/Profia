# Profia — AI-Powered Investing Insights

Profia is an AI-powered investing platform designed to help investors explore potential stock gains and losses, understand risk levels, and evaluate estimated success probabilities.

## Overview

Profia aims to make stock analysis more accessible by bringing investment insights and watchlist tools into one interface.

## Features

- **AI Stock Analysis** — Explore potential stock opportunities and risks.
- **Risk Insights** — Understand potential downside and investment risk.
- **Estimated Success Rates** — Review estimated probabilities as analytical guidance, not guarantees.
- **Watchlist** — Keep track of stocks you want to monitor.
- **Investment Dashboard** — Access stock research and analysis in one place.

## Tech Stack

Built with a modern web development stack. See `package.json` for the project's dependencies and tools.

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nathen-joseph/Profia.git
   ```

2. Navigate into the project:

   ```bash
   cd Profia
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server using the script configured in `package.json`:

   ```bash
   pnpm run dev
   ```
